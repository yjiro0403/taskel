# Android ホーム画面ウィジェット「今 / 次」 セットアップ手順

Taskel の Android アプリ（Capacitor）に、ホーム画面へ置ける「今 / 次」ウィジェットが入っています。
実行中タスクの残り時間と、次の時刻付きタスクまでのカウントダウンを、アプリを開かずに確認できます。

設計の詳細は [docs/now_next_widget_spec.md](now_next_widget_spec.md) の 6 章を参照してください。

## 1. APK を手に入れる

### 方法 A: GitHub Actions からダウンロード（ローカル環境不要・おすすめ）

`.github/workflows/android-apk.yml` が debug APK をビルドして成果物として保存します。

1. GitHub の **Actions** タブ → 左の **Android APK** を開く
2. 該当の実行（`android/` を変更した PR / main への push で自動実行。無ければ **Run workflow** で手動実行）を開く
3. ページ下部の **Artifacts** から `taskel-debug-apk` をダウンロードし、zip を展開して `app-debug.apk` を取り出す

### 方法 B: 手元でビルド

JDK 21 と Android SDK（platform 36 / build-tools 36）が必要です。手順は
[docs/alarm-setup.md](alarm-setup.md) の 5 章のとおりです。

```bash
npx cap sync android
cd android && ./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

## 2. 端末へインストール

サイドロードの方法（Google ドライブ経由 / ワイヤレス ADB / USB）は
[docs/alarm-setup.md](alarm-setup.md) の 6 章を参照してください。

> **署名の注意**: debug APK はビルドした環境の `debug.keystore` で署名されます。
> 別環境（Actions のランナー、別の Mac）で作った APK は署名が違うため、既に Taskel が
> 入っている端末では「既存のパッケージと署名が一致しません」で弾かれます。
> 一度アンインストールしてから入れてください（再ログインが必要になります）。
> Actions で毎回同じ署名にしたい場合は、手元の `~/.android/debug.keystore` を base64 化して
> リポジトリの secret `ANDROID_DEBUG_KEYSTORE_BASE64` に登録します。
>
> ```bash
> base64 -i ~/.android/debug.keystore | pbcopy   # macOS: クリップボードへ
> ```

## 3. ウィジェットを置く

1. アプリを起動して Taskel にログインし、タスク一覧が表示されるまで待つ（この時点で端末へ最初の同期が走る）
2. ホーム画面を長押し → **ウィジェット** → **Taskel** → 「Taskel 今 / 次」をホーム画面へドラッグ
3. 標準サイズは 4x2。横幅 3 セルまで縮められる

## 4. 何がいつ更新されるか

| 出来事 | ウィジェットの挙動 |
|---|---|
| アプリでタスクを再生 / 完了 / 追加 / 時刻変更 | アプリが開いている間は即時にウィジェットへ反映 |
| アプリをバックグラウンドから戻す | 復帰時に再同期 |
| 残り時間・あと何分 | 端末側の Chronometer が毎秒カウント（アプリ不要） |
| 次の開始時刻が来た | 「今すぐ」に切り替わる（アプリ不要） |
| 次の時間枠が過ぎた | その次の時刻付きタスクへ繰り上がる（アプリ不要。今日の残り最大 10 件を端末が持っている） |
| 実行中タスクが見積もりを超えた | 赤の「超過」に切り替わる（アプリ不要） |
| ログアウト | 「Taskel を開くと同期されます」表示に戻る |

右下の「更新 HH:mm」は、アプリから最後にデータを受け取った時刻です。
前日以前なら日付も付きます。表示が古いと感じたらアプリを一度開いてください。

### 制限

- ウィジェットは Supabase を直接読みません。**アプリを閉じている間に別の端末や Web で行った変更**（タスクの完了、新しい予定の追加など）は、次にアプリを開くまで反映されません。
- 実行中タスクの「超過」は、アプリでタイマーを止めるまで進み続けます。これは Taskel 側でもタイマーが走り続けているので正しい表示です。

## 5. トラブルシューティング

- **ウィジェット一覧に Taskel が出ない**: ウィジェット入りの APK（この機能が入った後のビルド）になっているか確認する。インストール直後は一覧に出るまで数秒かかることがある
- **「Taskel を開くと同期されます」のまま**: アプリを起動してログインし、タスク一覧まで表示させる。ログイン画面のままでは同期されない
- **数字が動かない / 古い**: アプリを開いて戻す。それでも直らなければ `adb logcat -s TaskelWidget` で `Rendered N widget(s)` が出ているか確認する
- **時刻の表記**: 開始時刻などは端末のロケール設定に従う（24 時間 / AM-PM）

## 6. 「今日の予定」ウィジェット

「今 / 次」に加えて、Google カレンダーの「スケジュール」に似た **今日の予定リスト** のウィジェットがあります。

1. ホーム画面を長押し → **ウィジェット** → **Taskel** → 「Taskel 今日の予定」をホーム画面へドラッグ
2. 標準サイズは 4x3。縦横ともにリサイズ可（最小 3x2）。行が収まらない分はスクロールできます

| 操作 | 挙動 |
|---|---|
| 右上の **+** | Taskel が開き、今日の日付で **タスク追加モーダル** が開く |
| 行をタップ | Taskel が開き、**そのタスクの編集モーダル** が開く |
| 日付をタップ | Taskel が開く |

表示されるのは **今日これからの時刻付きタスク** だけです（終了した予定・完了したタスク・時刻未設定のタスクは出ません）。実行中のタスクは青で「実行中」、開始時刻を過ぎて未着手のものは琥珀で「今すぐ」が付きます。時間枠が終わった行は、アプリを開かなくても自動で消えます。

> **Web のデプロイが必要**: リストの中身は Web 側が計算して送るため、この機能を含む Web が本番に反映されるまでは「この後の予定はありません」のままです。「+」と行タップも同様に、Web 側の対応が反映されてから動きます。
